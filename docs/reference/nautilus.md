# Data for moving average filter

Example data to be used with the
[`moving_avg_filter()`](https://maxgav13.github.io/GMisc/reference/moving_avg_filter.md)
function.

## Format

A data frame with growth line spacing data from a Silurian nautiloid

## References

Swan, A. R. H. & Sandilands, M. (1995). Introduction to Geological Data
Analysis. Blackwell Science.
